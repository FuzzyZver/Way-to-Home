# Way to Home

A PSX-inspired first-person horror game developed in Unity.

## About

Way to Home is a psychological horror experience where the player must walk home through a dark and dangerous neighborhood after visiting a local store.

The game focuses on atmosphere, tension and environmental storytelling rather than direct combat.

Inspired by classic PS1 horror aesthetics and modern indie horror games.

## Features

- First-person exploration
- Atmospheric horror gameplay
- PSX-inspired visual style
- Dynamic tension and environmental storytelling
- Multiple interactive objects

## Technologies

- Unity 6
- C#
- ECS Architecture
- Input System
- DOTween
- Cinemachine
